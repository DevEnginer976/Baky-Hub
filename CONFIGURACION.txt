BAKYHUB — VERSIÓN v12

ARCHIVOS
- index.html: formulario de acceso con solo username y contraseña; sin botón de Discord ni campo de correo.
- styles.css: interfaz renovada, adaptable a móvil, campos modernos y ventana para el código de respaldo.
- app.js: si el username existe intenta iniciar sesión; si no existe, crea la cuenta directamente. Al registrarse genera y muestra un código de respaldo una sola vez.
- supabase.sql: tablas, políticas RLS y trigger de perfiles. Conserva el archivo y los datos existentes.

SUBIR A GITHUB PAGES
1. Descarga el ZIP y extrae los archivos.
2. Sube index.html, styles.css, app.js y supabase.sql a la raíz del repositorio Baky-Hub. Reemplaza los archivos anteriores.
3. Haz commit y espera a que GitHub Pages termine el despliegue.
4. Abre https://devenginer976.github.io/Baky-Hub/ y presiona Ctrl+F5.

IMPORTANTE: LOGIN CON USERNAME
Supabase Auth no permite iniciar sesión con username de forma nativa. Para ocultar el correo de la interfaz, esta versión genera internamente una dirección técnica username@bakyhub.app y la usa con Supabase Auth. No se muestra ni se solicita correo al usuario.

El usuario no escribe ni necesita un correo real. Importante: Supabase Auth por contraseña sigue guardando internamente un identificador técnico con formato de correo; evitar también ese identificador requeriría crear un sistema de autenticación propio en un backend seguro.

Para que el registro funcione sin confirmar ese identificador técnico:
1. Supabase → Authentication → Sign In / Providers → Email.
2. Desactiva Confirm email.
3. Asegúrate de que los nuevos registros estén permitidos.
4. Ejecuta supabase.sql si aún no lo hiciste; el frontend necesita leer la tabla profiles para comprobar si el username ya existe.

Limitaciones de este método:
- Las cuentas creadas con el antiguo formulario de correo no podrán entrar usando su username con este método; deberán entrar con Discord si su cuenta está vinculada, o hacer una migración antes de usar la nueva modalidad.
- No hay recuperación de contraseña por correo en el formulario. Si necesitas recuperación segura, la alternativa recomendada es una Edge Function/backend para resolver usernames o volver a pedir un correo real.
- No reutilices contraseñas importantes en cuentas de prueba.


ACCESO SOLO CON USERNAME Y CONTRASEÑA
- La interfaz no pide correo ni muestra Discord.
- Supabase Auth necesita internamente un identificador con formato de correo. La web crea uno técnico usando username@bakyhub.app; la persona no escribe un correo real.
- El código que aparece tras el registro es un código de respaldo/referencia y se muestra una sola vez. En esta versión NO permite recuperar la contraseña ni reemplaza username y contraseña; no se debe presentar como una segunda clave de autenticación. Esa función requiere backend seguro adicional.

CONFIGURACIÓN DE SUPABASE PARA QUE REGISTRE
1. Supabase → Authentication → Sign In / Providers → Email.
2. Permite nuevos registros y desactiva Confirm email para que el usuario entre sin confirmar el identificador técnico.
3. Supabase → SQL Editor: ejecuta supabase.sql si todavía no lo ejecutaste. No borres tablas ni usuarios existentes.
4. Comprueba que el proyecto usa la URL y la clave pública configuradas en app.js. Nunca uses una service_role key en el navegador.

PUBLICAR EN GITHUB PAGES
1. Descarga el ZIP y extráelo en tu PC.
2. Sube los cinco archivos a la raíz del repositorio Baky-Hub y reemplaza los anteriores: index.html, styles.css, app.js, supabase.sql y CONFIGURACION.txt.
3. Haz commit y espera a que el despliegue de GitHub Pages termine.
4. Abre https://devenginer976.github.io/Baky-Hub/ y pulsa Ctrl+F5. Comprueba que no aparezca ningún botón de Discord.

IMPORTANTE
- Las cuentas antiguas creadas con un correo real no necesariamente podrán iniciar sesión con username@bakyhub.app; requieren migración o un método de acceso compatible.
- Si Supabase tiene Confirm email activado, la creación puede no abrir la red social automáticamente.
- El Client Secret de Discord que se compartió anteriormente debe regenerarse si aún existe; esta versión no usa Discord.
